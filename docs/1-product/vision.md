# Vision

Yggdrasil is an open-source software factory: it turns a written brief into working, verified
software by running coding agents inside sandboxes, through loops that check and fix their work and
approval points where humans decide direction.

It exists first to **learn** harness, loop and graph engineering by building them. Success is measured
by shipping real products with it and by benchmarking it against other factories.

It is **modular**: a factory is a composition of components that honour the Gungnir contract, so
factories specialised per use case (web SaaS, games, mobile) can be assembled from the same parts. And
it is **ouroboric**: it documents itself the way it documents what it builds, and is meant, in time, to
build and improve itself.

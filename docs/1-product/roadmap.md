# Roadmap

Order, not dates. Each step has its own design doc or change proposal.

1. **v0:** core (Odin, Gleipnir, Jormungandr, Gungnir), the web realm, metrics; builds client gallery
   lite. Built by hand following the SDD process (self-hosting stage 0).
2. **Iteration 2:** GitHub remote, bot identities and tracker; change graph; Go realm;
   `guardrail-change`; terminal UI; OpenTelemetry export; Next.js comparison realm; Spec Kit planning
   strategy; Ponytail cleanup job.
3. **Self-hosting stage 1:** Yggdrasil builds one of its own features.
4. **Spec 2:** the game realm.
5. **Spec 3:** the benchmark kit (Mimir); self-hosting stage 2.
6. **Later:** parallel agents, deployment, mobile, promotion (Bragi).

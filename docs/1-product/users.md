# Users

Yggdrasil has three kinds of user. The operator comes first.

- **The operator:** someone who runs their own Yggdrasil instance to build products. First, the
  project's author, building web SaaS and games to learn the discipline. Later, anyone using the
  open-source factory, each with their own private instance, apps and products, public or private.
- **Readers:** people following the journey through the journal and, later, blog posts.
- **Other factory builders:** people comparing factories through the shared benchmark format.

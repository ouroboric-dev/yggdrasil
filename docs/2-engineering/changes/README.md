# Change proposals

Each change to something that already exists gets one folder, `YYYY-MM-DD-<slug>/`. The folder holds
`proposal.md`, `delta.md` (added, modified and removed requirements) and `tasks.md`. A merged proposal
MUST move to `archive/` after its delta is folded into `../system/`. See
[spec-driven development](https://github.com/ouroboric-dev/ouroboric/blob/main/docs/4-ways-of-working/spec-driven-development.md#5-canonical-artifacts).

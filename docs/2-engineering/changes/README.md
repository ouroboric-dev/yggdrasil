# Change proposals

One folder per change to something that already exists: `YYYY-MM-DD-<slug>/` with `proposal.md`,
`delta.md` (added, modified and removed requirements) and `tasks.md`. Merged proposals move to
`archive/` after their delta is folded into `../system/`. See
[spec-driven development](../../4-ways-of-working/spec-driven-development.md#5-canonical-artifacts).

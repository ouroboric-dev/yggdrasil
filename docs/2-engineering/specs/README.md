# Specs

This folder holds engineering specs (RFC-like), one per initiative, named `YYYY-MM-DD-<slug>.md`.
Each spec MUST link to the design doc that it implements. A spec MUST NOT be edited after acceptance.
See
[spec-driven development](https://github.com/ouroboric-dev/ouroboric/blob/main/docs/4-ways-of-working/spec-driven-development.md#5-canonical-artifacts).
For v0, the design doc also carries the engineering decisions.
